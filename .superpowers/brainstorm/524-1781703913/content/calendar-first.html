Key Design Details

✨ Spa-Calendar Features

  • Gold gradient selected date with soft glow shadow
  • 30-minute interval time chips (matching existing minutesInterval: 5)
  • Full/unavailable slots shown in muted gray
  • Month navigation with clean arrow buttons
  • "Today" quick-jump pill
  • Gradient CTA button at the bottom
  • Selected date+time banner with warm gradient
  • Rounded cards matching the app's 14-20r border radius convention

📐 Technical Notes

  • Replaces omni_datetime_picker — no more third-party picker dependency
  • Built with showModalBottomSheet + custom widget
  • Flat weekday headers (一～日), no complex nested scrolling
  • State managed within the OrderController (no new controller needed)
  • Same 90-day forward window as current implementation

Date/Time Picker — Which design direction feels right?

The current omni_datetime_picker looks generic and clashes with the app's Warm Spa aesthetic

The Problem

Current picker uses default Material 3 colors — no warmth, no brand personality, no gold/amber tones. It looks like a generic system dialog dropped into a carefully designed app.

Three Design Approaches

A

🎨 Refined Omni Picker

Keep using omni_datetime_picker but apply a comprehensive custom theme — gold accent colors, rounded cards, warm surface tones, spa-appropriate typography. Quickest fix, good result.

B

🛠️ Custom Date+Time Picker

Build from scratch using Flutter's built-in showDatePicker + showTimePicker inside a custom dialog wrapper. Full control over every pixel. Matches the app perfectly, more work.

C

📋 Bottom Sheet Picker

Slide-up bottom sheet with integrated date & time panels, using custom-built calendar and timewheel widgets. Native iOS-feel with warm spa styling. Most distinctive, most work.
